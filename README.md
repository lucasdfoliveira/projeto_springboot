# Projeto escola de Spring boot

API Rest desenvolvida com Spring boot para desenvolvimetno backend

## 🚀 Tecnologias utilizadas:

- Java
- Spring boot
- Maven
- H2 Database
- Postman

## 📁 Estrutura do projeto:

O projeto segue com a arquitetura baseada na comunicação de uma API Rest

- CONTROLLERS (Interação com o cliente)
- SERVICE (Contrato de négocio)
- REPOSITORIES (Acesso e manipulação do banco de dados)

## 📌 Objetivo

Este projeto foi criado para praticar conceitos de:

- API REST
- Spring Boot
- Banco de dados
- Maven
- Versionamento com Git e GitHub
